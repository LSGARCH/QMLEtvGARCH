# QMLEtvGARCH
Quasi Maximum Likelihood Estimation for time varying GARCH models
In matlab 2023 or later.
For Simulated Data 
Add the path of the files to MATLAB, then run the corresponding function by its name.   
For example, in the MATLAB Command Window, type:  tvGARCH_local_estimation, to run the tvGARCH(1,1) simulations. 

For Real Data 
Extract the N225.rar file, add the path of the functions to MATLAB, and run the main script.
